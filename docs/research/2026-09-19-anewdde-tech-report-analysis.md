## 一、一句话结论

**这不是一篇论文，是一份「融资后集中亮相」的能力说明书。** 技术上真正硬的东西有两个：**分子胶三元复合物的结构预测**和**纳米抗体闭环设计里报出来的真实湿实验命中率**；其余部分是「把已有公开基准再跑一遍 + 自建内部基准」，且**关键口径不可比、方法几乎不披露**。战略上，它对中国 AI 制药赛道的定价和你所在的位置（AZ 临床前病理 + 多模态）都有直接影响——但**它完全没有碰病理图像**，这条边界值得记住。

## 三、技术骨架：四个模块拼成一台"引擎"

报告的核心叙事是「**今天的 AI 制药工具是碎片的**」：结构预测、亲和力评估、分子设计、实验决策各做各的，导致"构象合理 ≠ 结合强""排名第一 ≠ 有功能"。AnewDDE 声称把这四件事接成闭环。

```
AnewFold（结构）──► AnewAffinity（亲和力，秒级）
      │                    │
      └──► AnewDesign（生物药生成 + 湿实验闭环）
                           │
                AnewMind（百亿参数科学推理 LLM，决策层）
```

### 3.1 AnewFold —— 结构预测（这份报告最有分量的部分）

**训练数据口径（关键）**：只用 **2021-09-30 之前发布**的 PDB 条目，数据准备沿用 Protenix-v2 的流水线（附录 A.1）。这是一条**"截止线"声明**，让后面的"零样本泛化"主张有了基础。

**（1）抗体–抗原**

| 基准 | AnewFold | Protenix-v2 | IsoDDE |
|---|---|---|---|
| FoldBench-AB（低同源） | **76.2%** | 65.0% | 未评测 |
| PXMeter-AB（治疗相关抗体，516 条目） | **60.8%** | 49.7% | 未评测 |
| AF3-AB（71 条目） | **62.3%** | 53.5% | 未评测 |

- 对比 Protenix-v2 分别高出 **+11.2 / +11.1 / +8.8** 个百分点。
- **推理时扩展**：在 AF3-AB 上从 1 到 500 个 seed 全部领先 AF3 / Protenix-v1 / Protenix-v2；**单 seed 即超过 Protenix-v1 用 500 seed** 的成绩。
- 四个"近零同源"个案（PDB 7TXW / 8UKY / 8OXX / 8ZP2）DockQ 分别 0.885 / 0.614 / 0.490 / 0.894，而 Protenix-v2 分别为 0.028 / 0.031 / 0.004 / 0.103 —— 后者典型失败模式是**表位错位或界面翻转**。这几个例子挑得很好：都是表位同源度 4–8% 的极端情形。

**（2）蛋白–配体**

| 基准 | AnewFold | IsoDDE | AF3 | Protenix-v2 | OF3p2 |
|---|---|---|---|---|---|
| FoldBench 蛋白–配体（2023-01-13 后沉积） | **77.4%** | 76.0% | 64.9% | 64.0% | 44.5% |

- RNP 基准按"口袋–配体形状相似度"分层，**AnewFold 在全部相似度区间排第一，低相似度区间优势最大**（基线在那里崩得最快）。
- 个案：Cbl-b 变构口袋（近邻相似度仅 5.4%）、KRAS G12D Switch-II 隐蔽口袋、TRIM58 PRY-SPRY、mavacamten–心肌肌球蛋白——Protenix-v2 全部放错口袋（放进正交位点或既有表面）。

**（3）分子胶（真正的差异化）**

- 自建集合：在 MGTbind 基础上补 PDB，得 **131 个 2021-09-30 之后的三元复合物**。
- 联合成功率（DockQ>0.23 + 配体 RMSD<2.0 Å + LDDT-PLI>0.8）：

| AnewFold | Protenix-v1 | Protenix-v2 | Boltz-1 |
|---|---|---|---|
| **71.8%** | 45.0% | 29.8% | 22.1% |

**（4）盲口袋识别（不给配体）**

- AUPRC：总体 **0.751**，非隐蔽口袋 0.755，隐蔽口袋 **0.663**。
- 对照 IsoDDE 自报：0.750 / 0.760 / 0.630。**报告自己承认"两者评测集不同、标注口径不同，不可直接比较"**——这句话说得诚实。
- 按序列同源性分层：AUPRC 稳定在 0.700–0.827，**在 ≤20% 同源的靶点上仍有 0.700**，说明不是靠记同源蛋白。

**（5）apo→holo 构象变化**：三个例子（DCAF1 WD40、DppE 捕蝇草运动、USP7 隐蔽变构口袋），Cα RMSD 0.9 / 4.0 / 1.1 Å，口袋与配体 RMSD 到 0.42–1.46 Å。

### 3.2 分子胶个案：KAT2A–A1C5C–CRBN（本报告方法论最漂亮的一段）

设计思路值得学：**用文献里已经做过的突变实验来反向验证预测**。

- 实验已知：三元复合物靠三个接触面稳定（compound 面 / helix 面 / loop 面）；**突变 helix 面（K289A/V285A/R277A）或 loop 面（F109E/F202E/F183A/R206A）任一，细胞内 KAT2A 招募即消失**。
- AnewFold 只用 KAT2A 与 CRBN 序列 + 化合物，不用实验结构做模板，配合 AnewSampling 生成 **500 个构象**。
- 结果（热点接触在 500 个构象中出现的频率）：

| 接触残基 | 出现频率 |
|---|---|
| CRBN-F150（loop 面） | **99.6%** |
| KAT2A R206 | 99.0% |
| KAT2A F109 | 98.4% |
| KAT2A F183 | 97.8% |
| KAT2A R277（helix 面） | 88.0% |
| KAT2A F202 | 46.6% |
| KAT2A Y200（compound 面） | 35.8% |
| KAT2A K289 | 18.8% |
| KAT2A V285 | 8.0% |

- **被保留下来的最高频接触，正好是突变后功能丧失的那两套界面** —— 这一步把"几何预测"和"功能因果"接上了。
- 整体指标：DockQ 超过 Protenix-v2 基线（0.2879）的构象 346/500（69.2%）；配体 RMSD ≤2.47 Å 的 411/500（82.2%）；LDDT-PLI 超过基线（0.6142）的 334/500（66.8%）。

> ⚠ **要打折的地方**：上面三个"超过基线"的比例，比较对象是 **Protenix-v2 的单次预测**，不是实验真值。也就是说，"69.2% 的构象比 Protenix-v2 好" ≠ "69.2% 的构象是对的"。真正有说服力的是那张**热点残基频率表**。

### 3.3 AnewAffinity —— 亲和力预测

**定位**：FEP 准但慢（一条边几小时到几天），机器学习快但只给一个不透明的数。它想两头都占。

- **基准**：JACS 八靶点（BACE / CDK2 / JNK1 / MCL1 / p38 / PTP1B / thrombin / TYK2），199 个配体，按配体数加权聚合。
- **结果（同一批 199 配体，Boltz-2 由他们本地跑）**：

| 方法 | pairwise ΔΔG RMSE (kcal/mol) | Pearson r² | Spearman ρ |
|---|---|---|---|
| AnewAffinity | 1.057 | **0.553** | **0.724** |
| Boltz-2 | **1.016** | 0.486 | 0.620 |

**注意这张表**：数值误差 AnewAffinity **比 Boltz-2 更差**（高 0.04 kcal/mol），优势只在**排序能力**上。报告自己也承认"优势集中在候选排序而非一致更小的误差"。宣传口径写的是"near-FEP accuracy"，读的时候要接上这半句。

- **速度**：单条配体对边 **1.5 秒**端到端（含加载/推理/后处理）；四靶点摊薄成本 **3.4 秒/配体**（对应 Pearson r=0.76）。
- **可解释性（这段是真差异点）**：不只给一个数，而是给出**每个 alchemical 窗口的正/反向功分布**（每相 23 窗口），用 BAR 逐窗计算局部自由能再沿热力学循环累加。BACE 的 CAT-24→CAT-17e 留出案例：预测 **+1.12** vs 实验 **+1.33 kcal/mol**；两个相位的功分布与参考 FEP 的 Wasserstein-1 距离 0.246–0.314 RT，窗口级 ΔΔG MAE 0.133 / 0.180 kcal/mol。
- **判读**：这是把"我错了但我知道错在哪个窗口"变成产品特性——对药化团队有实际价值，比多 0.05 的 r² 更值钱。

### 3.4 AnewDesign —— 生物药闭环（本报告第二个硬结果）

**流程**：计算设计 → 湿实验（表达纯化 + SPR/BLI/ELISA）→ 数据回流 → 约束更新 → 再设计。跑在浏览器里的 agent（产品名 AnewScience），自然语言驱动。

**证据链（这是全文最实的一段）**：

| 轮次 | 投入 | 结果 |
|---|---|---|
| 生成 | 3092 个候选过初筛 → 287 个簇 | agent 自动过滤序列风险（脱酰胺/断裂/异构化/N-糖基化基序）+ 多样性聚类 |
| 第 1 轮湿实验 | **50 个** VHH 克隆（VHH-Fc 融合，CHO 瞬转，Protein A 纯化，CE-SDS 确认 ~80 kDa） | **7 个 SPR KD < 400 nM**（命中率 14%） |
| 第 2 轮（in silico 亲和力成熟后） | **100 个** 克隆 | **16 个 达个位数 nM KD**，亲和力最高提升约 **100 倍** |

- 合计：**150 个克隆里 16 个达到个位数 nM = 10.7% 成功率**（这就是摘要里的那个数）。
- SPR 平台：**Carterra LSA XT**，多浓度（300 nM 起 3 倍稀释），1:1 Langmuir 拟合。方法写在附录 A.3/A.4，够细，可复现性上比多数同类报告强。

**要打的折**：
1. 靶点是"**internal protein target**"，全文 **[masked]**——**无法判断这个靶点有多难**。如果是个容易的靶点，10.7% 的说服力会大打折扣。
2. 只报了结合亲和力 + 部分可开发性标签，**没有功能数据、没有成药性终判**。
3. 报告自己说这是"proof-of-concept … preview"，并承诺后续铺到"diverse, highly challenging array of disease-relevant targets"。**这句话就是最该盯的验证点。**

### 3.5 AnewMind —— 百亿参数科学推理 LLM

**做法**：对开源强推理 LLM 做**百亿参数规模的全参数后训练**（full-parameter post-training），模型叫 AnewMind Preview。没有说是基于哪个底座。

**（1）通用能力不掉**：MMLU-Pro 与 GPQA Diamond 上"与前沿通用模型大体可比"（正文未给点值，见图 13）。

**（2）ADMET 与可开发性**（零样本，模态分层）：

| 评测 | 指标 | 结果 | 17 个模型中的排名 |
|---|---|---|---|
| 小分子分类（13 端点） | 宏平均 Elo-AUROC | 0.771 | 第 5 |
| 小分子回归（9 端点） | 宏平均 Elo-Spearman | 0.520 | 第 5 / 16 |
| 环肽 PAMPA 渗透性 | Elo-AUROC | **0.737** | **第 1** |
| 抗体可开发性（7 属性） | 宏平均 Elo-Spearman | 0.247 | 第 2（距第一仅 0.007） |

- 强项：**CYP2C9 / CYP2D6 / CYP3A4 抑制**三个端点都是最高点估计（0.851 / 0.842 / 0.834），比第二名高 0.030 / 0.012 / 0.055；人肠道吸收 0.974、P-gp 抑制 0.876、BBB 0.867、hERG 0.862；水溶性 ρ=0.824。
- **弱项（报告主动说了）**：生物利用度、CYP2C9 底物、**DILI（药物性肝损伤）**、半衰期；**单体纯度是唯一负相关（ρ=−0.050）**。

**（3）评测方法上有一个值得注意的选择**：不要求模型预测绝对数值，而是**把它变成排序任务**——listwise 输出拆成两两偏好，用 **Elo** 聚合成全局相对评分，分类看 AUROC、回归看 Spearman。理由写得挺诚实：绝对点预测会把"单位理解错误/标定错误/格式错误"和"结构–性质关系没学到"混在一起，而且 LLM 对提示与选项顺序敏感。**代价是：这样评出来的强，可能有一部分是"格式鲁棒性"，不是化学理解。**

**（4）额外做了一个"防数据污染"的案例集**：从 **2026-01-02 公开的专利 WO 2026/002036 A1** 里抽四个配对案例（小鼠微粒体清除率、人微粒体清除率、小鼠血浆 Cmax、小鼠血浆半衰期），只给结构 + 实验背景、不给结果，让模型排序。

- **AnewMind Preview 4/4 全对**；对照 GPT-6-Astra 只对 1 个（半衰期），Gemini-3.8-Flash **两个清除率排序都反了**，GPT-5.6-Sol 把 Cmax 排反了。

**（5）PharmBench（自建决策基准）**：

- 规模：**50 个真实研发场景 / 200 道题**，覆盖 7 个能力维度（287 个能力标签）。
- 维度占比：立项决策与科学严谨性 29.0%、ADMET 26.0%、SAR 与数据解读 25.5%、分子设计与合成 23.0%、化学推理 18.0%、SBDD 16.5%、生物学与实验有效性 5.5%（非互斥，不合计 100%）。
- 设计要点：**专家出题，评分标准只基于"已经做过的实验及其观测结果"**；采用**渐进披露**——先给项目背景和第一个问题，答完才给下一题，防止后面题目泄漏答案。

## 五、方法学审查（用这份报告时要知道的坑）

1. **几乎所有对比都是自建的**。公共基准（FoldBench / RNP / JACS / TDC / CycPeptMPDB / GDPa3）用了，但**基线数值大量由自己重跑**，且多个关键比较明确写"不可直接比较"。
2. **不披露模型本身**。AnewFold / AnewAffinity / AnewDesign 没有架构、参数量、训练规模、算力；**没有代码或权重发布**。对照 IsoDDE 至少公开了报告口径。**这意味着"能不能复现"完全无从判断。**
3. **靶点盲测**。AnewDesign 的靶点全文 [masked]，无法评估难度。
4. **数值 vs 排序的偷换**。AnewAffinity 的 RMSE 实际输给 Boltz-2；摘要里的"接近 FEP 的精度"指的是排序相关性。
5. **速度对比是自认的"定性图"**。图 7 混合了不同数据集、不同硬件、不同计时定义，报告明说"不构成受控的加速基准"。IsoDDE 因无公开运行时间**干脆没画进去**。
6. **Elo 排序评测的两面性**：规避了绝对标定问题，但也让"格式遵循能力"混进了分数。
7. **PGM 口径**：PharmBench 的"科学严谨性"占 29%，权重很大——**这类题对"会写分点、会区分事实与假设"的模型天然有利**，可能高估了真实化学直觉。
8. **AnewMind 的底座未知**。百亿参数全参数后训练是真的（成本不低），但**不知道起点是哪个开源模型**，也就无法判断提升中有多少来自底座。

## 六、对可斯的三条直接关联（这才是重点）

### 1）岗位线：它恰好把"药物安全性"留出了一大块空白

- AnewMind 的 ADMET 22 个端点里，**DILI（药物性肝损伤）和半衰期是它自己承认的弱项**；**单体纯度是唯一负相关**。
- 更关键：**整份报告没有任何组织病理学 / 全切片图像（WSI）的内容**。他们的"安全性"是分子属性层面的（CYP、hERG、Ames、LD50），**不是病理形态学层面的**。器官芯片（MPS）也只在他们的公开材料里出现过，这份报告没写。
- 你在 AZ CPSS/PDS 做的事（临床前病理 + 多模态 → 加速安全性检测），**正好落在他们的能力边界之外**。这不是巧合——是他们主动选了小分子/抗体设计的赛道。

### 2）方法线：两个可以直接搬的做法

- **用文献里已做的突变实验反向验证预测**（KAT2A–CRBN 那段）。你做病理 AI 的外部验证时，同样可以找"已知功能必需的界面/通路"来做因果交叉验证，而不是只报 DICE/IoU。
- **窗口级/中间量级证据**（AnewAffinity 的逐窗自由能）。对应到病理：不要只给一个"毒性概率 0.83"，而是给出**哪几个区域、哪几个特征驱动了这个判断**——这才是病理学家愿意采信的形式。你之前写的 PLSR（安全性数据包）应该按这个思路设计交付物。

### 3）BD 线：这是一家应该进你合作名单的公司

- Anew Labs：字节控股 56%、估值 15 亿美元、**4 条管线、尚无 IND**、上海总部。
- 他们的公开材料里明确写了"**药物管线信息高度敏感，能私有部署、完全在组织控制内的模型是重要要求**"——**这说明他们对外部平台/合作有明确的合规洁癖**，也意味着他们需要**中国本地的临床前毒理病理产能与数据合规能力**。
- 你的第三条任务（对接中国高校与 startup，方向是"准备 license-out 的企业"）里，Anew Labs 属于**"平台很强但缺临床前验证产能"**的那一类——是 AZ 可以接的活。

### 4）顺带一条工具线（对见微系统）

PharmBench 上 **DeepSeek V4.1 Flash（53.3）明显高于 DeepSeek V4 Pro 0813（44.5）**，而且 GLM 5.3 / Kimi K3 / GLM 5.3 Flash 都在第一梯队。**别默认"pro 一定比 flash 强"**——这类长程推理任务上大模型不必然占优。见微现在的模型路由（flash 批量分析 / pro 晨报对话）值得用你自己的评测集复核一次。
